# Explainable Analysis of Uncertainty–Correctness Relationships in Multi-Step Data-Analysis Agents

## Research Direction

This project investigates how uncertainty in multi-step LLM-based data-analysis agents relates to the actual correctness of their intermediate and final actions.

The central research question is:

> **Why does an agent's uncertainty sometimes diverge from its actual correctness during multi-step execution, and what observable factors explain these mismatches?**

The project focuses on four uncertainty–correctness cases:

1. **High uncertainty + Correct**
2. **High uncertainty + Incorrect**
3. **Low uncertainty + Correct**
4. **Low uncertainty + Incorrect**

Particular attention is given to cases where uncertainty and correctness diverge, especially when an agent is uncertain despite being correct or confident despite being incorrect.

## Research Approach

The system will use a multi-step data-analysis agent that interacts with data through tools and produces an observable execution trajectory.

A trajectory is represented conceptually as:

`State → Action → Tool Execution → Observation → Next State`

The project will record these observable execution steps and analyze:

- uncertainty at different stages of execution
- correctness of observable actions and intermediate results
- accumulated errors across steps
- tool choices and tool outcomes
- task difficulty and ambiguity
- quality of intermediate results
- changes in uncertainty throughout the trajectory
- relationships between intermediate behavior and final correctness

The analysis will then identify candidate factors associated with uncertainty–correctness mismatches.

## Explainability and Intervention

The project does not treat an explanation generated by the agent itself as sufficient evidence of why a failure occurred.

Instead, candidate explanations will be derived from observable trajectory information and investigated using controlled interventions.

For selected mismatch cases, the project will modify an intermediate condition while keeping the surrounding task as controlled as possible. The resulting changes in uncertainty, subsequent actions, trajectory behavior, and correctness will be measured.

This provides intervention-based evidence for whether an observed factor is actually relevant to the mismatch.

## Research Scope

The project is focused specifically on:

- multi-step LLM-based data-analysis agents
- trajectory-level uncertainty
- observable correctness
- uncertainty–correctness relationships
- mismatch analysis
- factor identification
- controlled counterfactual intervention
- explainable evaluation of agent behavior

The project is **not** intended to build a general-purpose self-healing agent, another generic reliability framework, or a new foundation model.

## System Direction

The agent will be developed using a stateful agent orchestration approach, with explicit control over:

- agent state
- tool calls
- observations
- trajectory logging
- uncertainty estimation
- correctness evaluation
- intervention points

The exact model provider and implementation details will remain flexible so that experimental choices can be made based on feasibility, reproducibility, and evaluation requirements.

## Expected Outcome

The expected outcome is an empirical framework for studying uncertainty and correctness throughout multi-step agent execution rather than evaluating only the final answer.

The study aims to determine:

1. whether uncertainty reliably tracks correctness at different stages of execution;
2. where and when uncertainty–correctness mismatches occur;
3. which observable trajectory factors are associated with these mismatches; and
4. whether controlled interventions provide evidence that those factors influence subsequent agent behavior and correctness.

The project therefore treats **uncertainty, correctness, trajectory behavior, and intervention effects as connected components of the analysis**, rather than evaluating them independently.
